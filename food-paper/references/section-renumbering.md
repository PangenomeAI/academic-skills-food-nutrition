# Section Renumbering After Restructuring

Applies whenever a manuscript's sections are **reordered, added, removed, merged or
split** (format-convert, revise, finalize). If the original numbers its headings,
moving a section is only half the job: **the numbers must be re-checked.**

## Example
Original: `1. Introduction` → `2. Results` → `3. Methods`. The target journal puts
Methods before Results.

- Wrong: `1. Introduction` → `3. Methods` → `2. Results`
- Right: `1. Introduction` → `2. Methods` → `3. Results`

## Procedure
1. **Before editing,** list every numbered heading (all levels) and every
   cross-reference to one ("Section 3.2", "§2", "see 3.1").
2. Reorder to the order in the journal skill's structure.
3. **Renumber** top-level headings consecutively in the new order, then every
   subheading under its new parent (`3.1`, `3.2` become `2.1`, `2.2`).
4. **Update every cross-reference** using an old-to-new number map. Apply the map in
   one pass so a swapped pair (2 and 3) is not converted twice.
5. If moving text changes the order of first citation, also renumber **figures,
   tables, schemes, equations** and, in numbered styles, **references**.
6. If the journal uses unnumbered headings, remove the numbers and replace
   "Section N" cross-references with section names.
7. In Word files, update automatic heading numbering and cross-reference fields;
   do not type numbers over them. Preserve citation fields (`word-field-codes.md`).

## Double-check (required before delivery)
Re-read the **finished** file's headings from top to bottom and report the old-to-new
map. Confirm: no gaps, duplicates or out-of-order numbers; each subsection prefix
matches its parent; every cross-reference points to the intended content.
